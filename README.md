# سایت شخصی عرشیا دانش‌آرا

سایت شخصی دوزبانه (فارسی / انگلیسی) با کارت معرفی، فروشگاه و دانلود رایگان پک آموزش پایتون.

## صفحات

| فایل | توضیح |
| --- | --- |
| `index.html` | کارت معرفی، درباره من، علاقه‌مندی‌ها، برنامه‌ها و راه ارتباطی |
| `shop.html` | پک آموزش ۱۴ درسی پایتون (رایگان) و دو محصول «به زودی» |
| `blog.html` | صفحه‌ی «به زودی» برای نوشته‌ها |
| `assets/css/styles.css` | کامپوننت‌های پایه (دکمه، پنجره محصول، تنظیمات) |
| `assets/css/card.css` | ظاهر کارت وسط‌چین و تم اصلی سایت |
| `assets/js/data.js` | محصولات (دوزبانه) |
| `assets/js/i18n.js` | متن‌های رابط کاربری در دو زبان |
| `assets/js/app.js` | زبان، تم، رنگ، دانلود و رندر محتوا |
| `assets/downloads/Learn-Python.exe` | فایل دانلود پک ۱۴ درسی (۲۸٬۱۴۰ کیلوبایت) |

## اجرا

بدون هیچ ابزار ساختی کار می‌کند: کافی است `index.html` را در مرورگر باز کنید.

برای اجرای محلی با آدرس `http://localhost` (پیشنهادی برای تست دانلود):

```powershell
# اگر پایتون دارید
python -m http.server 5500

# یا اگر Node.js دارید
npx serve .
```

سپس `http://localhost:5500` را باز کنید.

> فونت‌ها از Google Fonts بارگذاری می‌شوند. بدون اینترنت، سایت با فونت‌های سیستم نمایش داده می‌شود و همه‌چیز کار می‌کند.

## شخصی‌سازی

### ۱. متن‌ها و اطلاعات تماس

- کارت معرفی، درباره من، علاقه‌مندی‌ها و متن‌های هر بخش در `assets/js/i18n.js` (کلیدهای `profile.*`، `home.*` و `fa` / `en`).
- ایمیل و تلفن در لینک‌های `mailto:` / `tel:` داخل `index.html`.
- عنوان و توضیح هر صفحه در تگ `<head>` همان فایل.

### ۲. محصولات

در `assets/js/data.js` آرایه‌ی `PRODUCTS` را ویرایش کنید:

```js
{
  id: "my-product",
  art: 1,                    // گرادیان کارت، ۱ تا ۳
  symbol: "Py",              // نوشته‌ی بزرگ روی کارت
  price: 0,                  // تومان
  comingSoon: false,         // برای محصول «به زودی» true
  badge: { fa: "رایگان", en: "Free" },
  tags: [{ fa: "پایتون", en: "Python" }],
  name: { fa: "...", en: "..." },
  tagline: { fa: "...", en: "..." },
  desc: { fa: "...", en: "..." },
  features: { fa: ["..."], en: ["..."] },
  download: "assets/downloads/file.exe",  // فقط برای محصول آماده
  downloadName: "File.exe"
}
```

برای عوض کردن فایل دانلود، فایل جدید را در `assets/downloads/` بگذارید و `download` و `downloadName` را به‌روز کنید.

### ۳. بلاگ

بلاگ فعلاً فقط صفحه‌ی «به زودی» است. برای فعال کردن نوشته‌ها باید ساختار فهرست و صفحه‌ی مقاله دوباره اضافه شود.

### ۴. رنگ و ظاهر

- در پنل تنظیمات (چرخ‌دنده پایین صفحه) شش رنگ اصلی و حالت روشن/تیره انتخاب می‌شود و در مرورگر ذخیره می‌شود.
- برای عوض کردن رنگ‌های از پیش تعریف‌شده، بلوک‌های `[data-accent="..."]` در ابتدای `assets/css/styles.css` را ویرایش کنید.

### ۵. عکس اشتراک‌گذاری

`assets/img/og-cover.png` را با تصویر خودتان (۱۲۰۰×۶۳۰) عوض کنید. بعد از اتصال دامنه، آدرس `og:image` را در `<head>` صفحه‌ها به آدرس کامل تبدیل کنید.

## دانلود پک

- لینک دانلود مستقیم است و با کلیک روی کارت یا دکمه‌ی «دانلود پک» شروع می‌شود.
- فایل `Learn-Python.exe` با حجم ۲۸٬۱۴۰ کیلوبایت در پوشه‌ی دانلود مرورگر ذخیره می‌شود؛ مسیر ذخیره به تنظیمات مرورگر بستگی دارد.
- دو محصول دیگر با برچسب «به زودی» نمایش داده می‌شوند و دکمه‌ی غیرفعال دارند.

## انتشار روی اینترنت

- **Netlify:** پوشه‌ی `arshia-site` را در [app.netlify.com/drop](https://app.netlify.com/drop) رها کنید. سپس دامنه را وصل کنید.
- **GitHub Pages:** فایل‌ها را در یک ریپازیتوری بریزید و از Settings → Pages، شاخه‌ی اصلی را انتخاب کنید.
- **هاست اشتراکی/cPanel:** محتویات پوشه را در `public_html` آپلود کنید.

پس از انتشار، گواهی SSL (https) را فعال کنید. فایل اجرایی حجیم است؛ مطمئن شوید هاست اجازه‌ی دانلود فایل `.exe` را می‌دهد.

## نکته‌ها

- سبد خرید و درگاه پرداخت حذف شده‌اند؛ فروشگاه فقط دانلود مستقیم و محصولات «به زودی» دارد.
- اگر JavaScript مرورگر خاموش باشد، کارت‌های محصول نمایش داده نمی‌شوند؛ بقیه‌ی متن‌ها در HTML هستند.
- متن‌ها و محصولات فعلی نمونه‌اند؛ قبل از انتشار، عنوان‌ها، قیمت‌ها و توضیحات را با اطلاعات واقعی جای‌گزین کنید.
